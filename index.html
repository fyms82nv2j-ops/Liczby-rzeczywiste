JAK KORZYSTAĆ

Małe kroki

Przejdź kolejne zakładki. W każdej znajdziesz teorię, przykład i interaktywną ilustrację. Na końcu rozwiąż quiz — wynik zapisuje się podczas korzystania z tej strony.

Wskazówka: zanim odsłonisz rozwiązanie, spróbuj wyjaśnić regułę własnymi słowami.

Mapa liczb rzeczywistych

Każda liczba rzeczywista leży na osi liczbowej. Liczby wymierne i niewymierne razem tworzą zbiór ℝ.

Schemat pokazuje podział ℝ na liczby wymierne ℚ i niewymierne. Zbiory ℕ oraz ℤ są podzbiorami ℚ.

TEORIA

Zbiory liczb

ℕ — naturalne (w tym kursie przyjmujemy 0 ∈ ℕ). ℤ — całkowite. ℚ — wymierne, czyli dające się zapisać jako ułamek dwóch liczb całkowitych z niezerowym mianownikiem. ℝ\\ℚ — niewymierne.

ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ

Liczba wymierna ma rozwinięcie dziesiętne skończone lub okresowe. Niewymierna ma nieskończone, nieokresowe rozwinięcie dziesiętne.

Uwaga: w niektórych podręcznikach ℕ zaczyna się od 1. Sprawdź konwencję przyjętą przez nauczyciela.

Sprawdź liczbę

Wpisz liczbę, by zobaczyć jej klasyfikację.

0,75 jest liczbą wymierną.

Klasyfikator rozpoznaje przykładowe liczby i proste zapisy. To pomoc do nauki, nie pełny system algebry.

Wartość bezwzględna = odległość

|x| to odległość liczby x od zera, więc nigdy nie jest ujemna.

|x| = x dla x ≥ 0;   |x| = −x dla x < 0

Zapamiętaj: wartość bezwzględna odpowiada na pytanie „jak daleko?”, a nie „w którą stronę?”.

POTĘGI

Prawa działań

aᵐ · aⁿ = aᵐ⁺ⁿ
aᵐ / aⁿ = aᵐ⁻ⁿ
(aᵐ)ⁿ = aᵐⁿ
a⁰ = 1, a⁻ⁿ = 1/aⁿ

Przy dzieleniu podstawa musi być niezerowa. Dla ujemnych wykładników także a ≠ 0.

Pułapka: (−2)² = 4, ale −2² = −4. Nawias zmienia kolejność działań.

Potęgi w ruchu

Zmień wykładnik i zobacz, jak zmienia się wartość 2ⁿ.

2³ = 8
Wykładnik: 3

Ujemny wykładnik oznacza odwrotność: 2⁻³ = 1/2³ = 1/8.

PIERWIASTKI

Pierwiastek to odwrotność potęgowania

√a = b ⇔ b² = a (a ≥ 0, b ≥ 0)

W liczbach rzeczywistych pierwiastek parzystego stopnia wymaga nieujemnego podpierwiastkowego. Pierwiastek nieparzystego stopnia może mieć argument ujemny.

√(ab) = √a · √b

Dla pierwiastków kwadratowych w tej regule wymagamy a ≥ 0 i b ≥ 0.

Przykład: √72 = √(36·2) = 6√2.

Uprość pierwiastek

Wybierz liczbę. Spróbuj wyciągnąć największy kwadrat spod pierwiastka.

Na przykład √12 = √(4·3) = 2√3.
LOGARYTMY

Logarytm odpowiada na pytanie „do jakiej potęgi?”

logₐ b = c ⇔ aᶜ = b

Warunki: a > 0, a ≠ 1, b > 0. Podstawa nie może być ujemna ani równa 1, a argument musi być dodatni.

logₐ(xy) = logₐx + logₐy
logₐ(x/y) = logₐx − logₐy
logₐ(xʳ) = r logₐx
Wzory na iloczyn i iloraz wymagają dodatnich argumentów x i y. Logarytm iloczynu nie jest iloczynem logarytmów.

Maszyna logarytmiczna

Ustaw podstawę i wykładnik. Maszyna obliczy aᶜ = b, czyli pokaże logₐ b = c.

2³ = 8
log₂ 8 = 3

Logarytm jest wykładnikiem potęgi, a nie kolejnym działaniem do zapamiętania na ślepo.

Przykład krok po kroku

log₂ 32 = x2ˣ = 322ˣ = 2⁵x = 5

Gdy obie strony można zapisać jako potęgi tej samej podstawy, porównaj wykładniki.

PRZEDZIAŁY

Czy końce należą?

(a,b) — końce wyłączone. [a,b] — końce włączone. Mieszane nawiasy oznaczają jeden koniec włączony, drugi wyłączony. Przy nieskończoności zawsze używamy nawiasu okrągłego.

x ∈ [2, 5) ⇔ 2 ≤ x < 5
Na maturze zwracaj uwagę, czy nierówność jest ostra (<, >) czy nieostra (≤, ≥).

Oś przedziału

Wybierz rodzaj końców i obserwuj zapis.

[2, 5)

2 należy do przedziału, 5 nie należy.

Wartość bezwzględna a przedziały

Równanie |x−3| = 2 oznacza, że odległość x od 3 wynosi 2. Są więc dwa rozwiązania: x = 1 lub x = 5.

x − 3 = 2lubx − 3 = −2→ x = 5 lub x = 1

Twoja strategia

Cel: umieć uzasadnić każdy krok, nie tylko otrzymać wynik.
